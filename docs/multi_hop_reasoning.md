# Multi-Hop Reasoning Architecture

## Motivation
Certain complex regulatory and academic questions cannot be satisfied by single-turn passage retrieval (e.g., cross-referencing prerequisite grade thresholds with fee waiver policies).

## Process
1. Query decomposition & Hop 1 retrieval.
2. Intermediate claim generation.
3. Query reformulation & Hop 2 contextual evidence gathering.
4. Synthesized final grounded citation generation.
