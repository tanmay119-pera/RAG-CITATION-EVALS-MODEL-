# Contributing to RAG Citation Evals

Thank you for contributing!

## Quickstart

1. Install requirements: `pip install -r requirements.txt`
2. Run test suite: `PYTHONPATH=src python3 -m unittest discover -s tests -v`
3. Check code style: follow PEP 8 and conventional commit messages.

## Pull Requests

- Keep each change focused on a single responsibility.
- Add accompanying unit tests in `tests/`.
- Ensure all tests pass prior to submitting.
